# Assignment 6 — jQuery

A small front-end project for practicing jQuery selectors, effects, DOM manipulation, forms, and animations. Pages are connected with a navigation bar. The mini project is an FAQ accordion.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser. An internet connection is needed to load jQuery from its CDN and the sample photos.
3. Open the browser developer console on the Selectors page to see `jQuery is ready!`.

## Before submitting

- Replace “Write your full name” and “Write your group” on the home page.
- Publish the repository with GitHub Pages (Settings → Pages → deploy from the main branch) or upload it to Netlify.
- Submit the repository link in Moodle and be ready to explain the code during practice.

## Pages

- `pages/selectors.html` — setup, selectors and CSS
- `pages/effects.html` — hide/show/toggle, fade and slide
- `pages/dom.html` — list, attributes and live form
- `pages/animations.html` — basic, sequential and combined animations
- `pages/project.html` — FAQ accordion mini project

jQuery is loaded from the official jQuery CDN. The examples use plain HTML, CSS, and JavaScript.
